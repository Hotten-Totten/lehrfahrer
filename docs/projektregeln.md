# Projektregeln

Diese Entwicklungsregeln sind für das gesamte Lehrfahrer-Projekt verbindlich.

## Grundsätze

- Lehrfahrer unterstützt Menschen, ersetzt sie nicht.
- Nutzerfreundlichkeit hat Vorrang vor technischer Spielerei.
- Offlinefähigkeit hat hohe Priorität.
- Dokumentation gehört zur Entwicklung.
- Änderungen müssen nachvollziehbar bleiben.
- Keine unnötigen Frameworks einsetzen.
- Keine unnötigen Abhängigkeiten hinzufügen.
- Die bestehende Architektur möglichst erhalten.
- Neue Funktionen modular entwickeln.
- PDFs richten sich an Menschen, nicht an Maschinen.
- Die Bedienung muss klar und einfach sein.
- Vor jeder größeren Änderung eine Planung durchführen.

## Git-Workflow

Analyse → Umsetzung → Test → Commit → Push
