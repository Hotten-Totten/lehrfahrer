# Codex-Regeln

Diese Regeln sind für die Arbeit von Codex innerhalb des Lehrfahrer-Projekts verbindlich.

## Kommunikation

- Antworten kurz halten.
- Keine langen Erklärungen geben.
- Möglichst wenig Tokens verbrauchen.
- Standardausgabe verwenden:
  - Status
  - Geänderte Dateien
  - Kurzfassung
  - Tests
  - Nächster Schritt

## Änderungen

- Keine automatischen Commits erstellen.
- Keine automatischen Pushes durchführen.
- Keine Refactorings ohne ausdrücklichen Auftrag vornehmen.
- Keine Modernisierung ohne ausdrücklichen Auftrag durchführen.
- Nur notwendige Änderungen umsetzen.
- Möglichst komplette Funktionen ändern, statt Änderungen unnötig über viele Stellen zu verteilen.
- Die bestehende Architektur respektieren.
- Vor Änderungen mögliche Seiteneffekte prüfen.
- Stabilität hat Vorrang vor Eleganz.
