# PDF 3.0 Integrationsplan

## 1. Aktueller Stand

- PDF 3.0 Preview V2 existiert.
- Das Layout ist für die Integration ausreichend.
- Die bestehende Produktiv-PDF ist unverändert.

## 2. Ziel

- PDF 3.0 als neue Streckeneinweisung produktiv nutzbar machen.
- Die alte PDF zunächst als erreichbaren Fallback behalten.

## 3. Nächste technische Schritte

1. Datenübergabe zwischen Editor, Export-Endpunkt und PDF-Generator prüfen.
2. Den bestehenden PDF-Export-Endpunkt und alle Aufrufstellen eindeutig identifizieren.
3. PDF 3.0 über eine optionale, rückwärtskompatible Auswahl zuschaltbar machen.
4. Bei Fehlern und für bestehende Arbeitsabläufe den Fallback auf die alte PDF erhalten.
5. PDF 3.0 mit echten Linien, Varianten und älteren Projektdateien testen.
6. Nach erfolgreicher Abnahme PDF 3.0 zum Standard machen und die spätere Ablösung der alten PDF planen.

## 4. Nicht mehr Teil des aktuellen Sprints

- weiterer Layout-Feinschliff
- neue Designvarianten
- QR-Code
- Mandantenbranding
- Karten oder Fotos

## 5. Akzeptanzkriterien

- PDF 3.0 kann aus dem Editor erzeugt werden.
- Die alte PDF bleibt erreichbar.
- Es sind keine technischen Daten sichtbar.
- Echte Projektdaten werden korrekt übernommen.
- Der Export funktioniert mit bestehenden Linien.
